# Real Estate Upwork Project
**Owner:** Daniel Schley (AIOptsExpert.com)
**Started:** June 2026
**Stack:** Static HTML · Tailwind CSS (CDN) · Vanilla JS

---

## What This Is
An operations dashboard built for an Upwork real estate client.
Delivered as static HTML — no build step, no npm, no framework.
The main `index.html` is the root landing/overview page.
`dashboard/` contains the detailed client dashboard.

## How to Run
Open `index.html` directly in a browser, or use Live Server in VS Code.
No install required.

## Key Files
| File/Folder | Purpose |
|-------------|---------|
| `index.html` | Root page — aiopsexpert.com operations dashboard |
| `dashboard/` | Client-facing dashboard views |
| `docs/plans/` | Feature plans and client requirements |
| `.claude/` | Claude Code project config |

## Rules
- No frameworks, no npm, no build tools — keep it static
- Tailwind loaded via CDN script tag — do not add a build pipeline
- All styling inline or in `<style>` tags — no separate CSS files unless already present
